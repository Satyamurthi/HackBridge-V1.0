## About HackBridge

**HackBridge** is an institutional competitive platform engineered to replace messy spreadsheet tracking, unverified payment screenshots, and chaotic communication with a **deterministic, cryptographically verified infrastructure**.

Built for universities and colleges hosting high-stakes competitive hackathons, HackBridge delivers permanent credentials, atomic problem allocation, automated GitHub sync, and unified real-time judging — all in one platform.

---

## ✨ Core Features

| Feature | Description |
|---|---|
| 🔐 **Permanent Credentials** | Every student mints a permanent, collegiate-verified Hackathon ID that records their multi-event history. |
| ⚡ **Atomic Allocation** | Transactional row locking eliminates overbooking and ensures mathematically balanced problem statement slots. |
| 🖥️ **GitHub Auto-Sync** | Automated repository provisioning and commit verification preserves student engineering code forever. |
| 🏆 **Unified Evaluation** | Real-time multi-judge scoring with normalized weighted rubrics, live audit trails, and instant leaderboards. |

## 🚀 Getting Started

For complete setup instructions (frontend & backend), refer to **[SETUP.md](./SETUP.md)**.

**Quick start:**

```bash
# Install dependencies
npm install

# Set up environment variables
cp .env.example .env.local

# Run database migrations
npx prisma migrate dev

# Start development server
npm run dev
```

The app will be available at `http://localhost:3000`.
